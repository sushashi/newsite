# Waddles on Ice

A tiny, dependency-free penguin game. Collect fish, dodge snowballs, and try to retain some dignity.

## Play locally

Open `index.html` in a browser, or serve this folder with any static file server.

- Move with the arrow keys or WASD.
- On touch screens, use the directional buttons below the rink.
- Collect fish to increase your score. Three snowball bonks end the round.
- Your best score is saved in this browser.

## Publish with GitHub Pages

1. Push these files to a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select the branch containing the game and the **/(root)** folder, then save.

The site is static and uses relative asset paths, so it works at a GitHub Pages project URL without a build step.
